# EPort Frontend

Angular frontend for the EPort healthcare appointment booking system.

## Installation

1. Install dependencies:

```bash
npm install
```

2. Start the development server:

```bash
npm start
```

The application will be available at `http://localhost:4200`.

## Build

```bash
npm run build
```

## Project Structure

- `src/app/` - Angular modules, routes, pages, services
- `src/assets/` - Static assets
- `src/styles/` - Global styles

## Notes

- Frontend API URLs are currently configured in Angular service files under `src/app/services/`.
